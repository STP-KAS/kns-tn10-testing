# KNS TN10 storm runner (prepared 2026-10-01, NOT started)

TN10 only. Funds only from leftover snapshot-wallet balances (no treasury/farm UTXOs; treasury address hard-blocked as input).
Broadcast requires `./start.sh GO` (sets KNS_STORM_GO=1 + --broadcast 1). Default rate 30/min, hard cap 30/min. DEFAULT --owner-mode payer (random affordable snapshot wallet pays commit AND owns/signs reveal; proven 26 Sep). --owner-mode split is opt-in (OWNER_MODE=split ./start.sh GO).
stp decision: run at 30/min until leftover wallet funds run out, then the runner stops itself (exit_reason funds_exhausted) and writes final-summary.json. No treasury top-up.

- Start: `cd /workspace/artifacts/kns-tn10/storm-2026-10-01 && ./start.sh GO 30 24`
- Stop (clean): `./stop.sh` (touches STOP, drains in-flight, exits); `./stop.sh --hard` also SIGTERMs (same graceful drain)
- Live summary: `node summary.mjs --window-min 10`
- Offline dry-run (never submits): `node kns-storm-runner.mjs --dry-run 50`

Price: 35 TKAS per 5+ char label (1-2: 4200, 3: 2100, 4: 525). Labels: random [a-z0-9], first char a letter, length 5-10.
Per name (payer-mode dry-run, 1x fees): commit ~0.0124 + reveal 0.0220 + 35 = ~35.034 TKAS.
Leftover funds (public resolver, 2026-10-01 18:42 CEST): 652,695.45 TKAS in 23,931 wallets.
Payer mode: only wallets that can afford a whole name alone (726 wallets, 357,671 TKAS) are usable.
Run-to-exhaustion (offline): 9,511 names, then no wallet can afford one; ~319,482 TKAS stays in wallets below ~37 TKAS.
At 30/min: 1,800 names/h, ~63,062 TKAS/h => ~5.3 h (~5 h 17 min) until funds_exhausted stop.
(split mode would reach 17,816 names / ~9.9 h, but owner attribution in that mode is unproven.)

Logs: events.jsonl, names.jsonl, public-api-calls.jsonl, status.json, stranded.jsonl, final-summary.json, runner-stdout.log, runner.pid.
